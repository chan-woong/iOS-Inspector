# 사용 가이드

## 기본 흐름

프로그램의 모든 점검 기능은 SSH 연결을 우선합니다.

1. 상단에서 USB 단말을 선택합니다.
2. **SSH 터미널** 탭에서 연결합니다.
3. 연결이 성공하면 미러링, 파일 탐색기, 앱 설치 탭을 사용합니다.

## SSH 터미널

- **IP로 연결:** 단말 IP, SSH 포트, 사용자, 비밀번호 입력 후 선택합니다.
- **USB SSH 연결:** USB 로컬 포트를 입력한 뒤 선택합니다. 프로그램이 `iproxy`를 시작하고 `127.0.0.1`로 연결합니다.
- 아래 입력창에 명령을 쓰고 Enter 또는 **전송**을 누릅니다.
- IP, 포트, 사용자 이름은 다음 실행을 위해 저장되지만 비밀번호는 저장하지 않습니다.

## 화면 미러링과 제어

1. TrollVNC를 먼저 설치합니다.
2. VNC 포트는 기본값 5901을 사용합니다.
3. **USB 연결**을 권장합니다. 단말의 VNC 서버가 localhost에만 바인딩되고 `iproxy`를 통해 연결됩니다.
4. 화면을 클릭하면 키보드 포커스를 얻습니다.

지원 입력:

- 마우스 클릭 및 드래그
- 휠 스크롤
- 문자, Enter, Tab, Backspace, Delete, 방향키
- Ctrl+C/V/X/A/Z를 iOS Command+C/V/X/A/Z로 변환
- 하단의 뒤로, 홈, 앱 전환, 잠금, 음량, 음소거, 화면 캡처 버튼

Windows와 iPhone 사이의 클립보드 내용 동기화는 제공하지 않습니다.

## 파일 탐색기

파일 탭은 Apple File Conduit(AFC)가 공개하는 영역을 탐색합니다.

- 경로 입력 후 **이동**
- 폴더 더블 클릭
- 파일 업로드 및 다운로드
- 새 폴더 생성
- 선택한 파일 또는 폴더 삭제

일반 AFC 연결은 iOS 전체 루트 파일시스템을 노출하지 않습니다. 루트 경로 작업이 필요하면 SSH 터미널을 사용하세요.

## IPA 설치와 재서명

1. IPA 파일을 입력칸으로 드래그하거나 **찾아보기**로 선택합니다.
2. 프로그램이 기존 서명 상태를 확인합니다.
3. 탈옥 단말 설치를 선택하면 SSH에서 `appinst` 또는 `ipainstaller`를 찾습니다.
4. 설치 도구가 없으면 rootless `appinst` 패키지 자동 설치를 시도합니다.
5. 재서명이 필요하면 단말의 `ldid`를 이용해 fake signing한 뒤 설치합니다.

일반 단말용 P12와 provisioning profile 서명은 고급 옵션입니다. 인증서, App ID, entitlements, 등록 UDID가 서로 일치해야 합니다.
